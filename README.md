# quantlab

Laboratorio de investigación cuantitativa.

Motor de análisis que recibe cualquier panel de series temporales
—precios de instrumentos o PnL de estrategias, en cualquier timeframe—
y devuelve su estructura de riesgo: correlación, factores latentes,
filtrado de ruido y número efectivo de apuestas independientes.
